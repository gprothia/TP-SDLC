# Track My Rescue (Live)

A static single-page prototype showing what a stranded AAA member sees while waiting for roadside assistance:

- **Live ETA countdown** in minutes with reassurance messaging.
- **4-step progress tracker**: Received → Truck assigned → On the way → Arrived.
- **Simple live map** with an animated tow truck moving along the route toward the member.
- **Driver details**: name, truck, rating, and phone number (fake data only).
- **Member actions**: Call driver, share a live tracking link with family, or cancel the request.

All data is fake and runs client-side with plain HTML, CSS, and JavaScript.
